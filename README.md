# Schematic Diagrams

A collection of interactive and educational schematic diagrams covering radio engineering, electronics, telecommunications, and related technical topics.

## About

This repository contains visual and interactive demonstrations of electronic circuits, radio equipment, and engineering concepts.

The primary goal is educational: helping students, hobbyists, engineers, and historians understand how various devices and systems work through animated diagrams and detailed explanations.

## Features

* Interactive HTML-based schematic diagrams
* Animated signal flow visualization
* Block-by-block explanations
* Historical radio equipment demonstrations
* Educational engineering references
* Self-contained projects with no external dependencies

## Current Diagrams

### Radio Station "Sever"

An interactive educational model of the Soviet portable radio station **"Sever"**.

Features:

* Receive (RX) mode visualization
* Transmit (TX) mode visualization
* Morse key simulation
* Automatic CQ transmission animation
* Signal path highlighting
* Power supply visualization
* Interactive component descriptions
* Step-by-step operation guide

## Usage

Simply open any HTML file in a modern web browser:

```bash
open index.html
```

or deploy it to:

* GitHub Pages
* GitLab Pages
* Netlify
* Cloudflare Pages

No installation or build process is required.

## Educational Purpose

All diagrams in this repository are intended for educational and historical study purposes.

The animations and schematics demonstrate operating principles and signal flow rather than providing construction or operating instructions for real-world radio transmitters.
